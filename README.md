# Monitoramento-Fluxo-de--gua-ESP32
Protótipo de monitoramento de fluxo de água com ESP32, sensor YF-S201, display OLED SSD1306 e LED de alerta. Conta os pulsos do sensor por interrupção, calcula frequência e vazão (L/min) e exibe os dados em tempo real. Simulado no Wokwi, com evolução planejada para medição de nível e alerta de enchentes.
